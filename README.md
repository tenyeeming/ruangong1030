# 1030course — 軟體工程課堂 Hackathon

大三軟體工程 10/30 課堂資料：1151 課堂 Hackathon 需求說明。

## 目錄結構

| 檔案 | 用途 |
|---|---|
| `1151 Hackthon說明 (1).ppt` | Hackathon 進行規則與需求（活動報名平台：基本款 / Pro 版） |

## 需求摘要

- **進行規則**：小組建立 GitHub 專案協作；設計共用資料表並匯出 SQL push 上 GitHub；模組分工，每位組員各自 commit 負責部分；向助教展示。
- **基本款（活動報名平台）**：新增活動、列出可報名活動、點擊報名填表（姓名、電話）、送出報名、查看活動報名清單。
- **Pro 版**：清單顯示目前報名人數、檢查重複報名（同名且同電話）、截止報名功能。
